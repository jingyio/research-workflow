# Literature Research Module

This is the only active research module in the repository.

## Outputs

- a versioned research map;
- a targeted reading queue;
- paper cards tied to decision questions;
- a claim/evidence ledger;
- a contradiction log;
- a gap map;
- a weekly synthesis describing what changed in the idea.

## Rule of thumb

A paper is not "relevant" merely because it shares keywords. It is relevant when it can change a decision, establish a mechanism class, expose a limitation, define a dataset/evaluation regime, or anchor a later executable baseline.
