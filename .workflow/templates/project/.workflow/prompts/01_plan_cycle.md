# Prompt — 规划下一轮 Literature Cycle

目标：只设计一轮**能够改变研究决策**的文献调研，不立即执行搜索。

先读取当前 Idea State、open questions、已有 literature synthesis、claim ledger、reading queue 和 handoff。选择一个最高 decision value 的 unresolved question。

用中文输出并写入对应 cycle 文件：

## 1. 本轮决策问题
- 一个清晰、可被证据改变的问题；
- 为什么现在必须解决；
- 不同答案分别会如何改变当前方向。

## 2. 当前先验
- 当前倾向是什么；
- 哪些只是直觉，哪些已有证据；
- 什么结果会支持 / 削弱 / 否定 / 收缩该判断。

## 3. 互补检索路线
从 `research/literature/routes.md` 选 2–5 条 route。每条 route 写明：
- 它独立减少什么不确定性；
- 它专门防止哪类误判；
- inclusion / exclusion criteria。

至少包含一条主动寻找 disconfirming evidence 的路线。

## 4. Search queries
给出多组英文搜索 query；不要假设项目内部术语就是领域标准术语。

## 5. 预期高价值证据
明确什么类型的论文/数据/失败结果最可能改变判断。

## 6. Stop conditions
定义何时停止继续扩张 paper pool。

## 7. 执行计划
说明执行时先搜什么、再读什么，以及最多需要深入多少类互补证据。

本阶段不要宣称 novelty，不要修改核心 idea，不要开始模型设计。完成后等待研究者批准，或在用户明确授权时进入 `02_execute_cycle.md`。
