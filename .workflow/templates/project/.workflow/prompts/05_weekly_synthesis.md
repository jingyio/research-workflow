# Prompt — 本周研究综合

只基于 repository 中已有的 research state、Paper Cards、claim ledger、contradiction log、gap map、cycle 记录和 handoff 做总结。不要凭记忆补论文事实。

用中文输出并更新 `research/literature/synthesis/weekly_update.md`：

1. **本周真正解决了什么问题**；
2. **发生变化的 3–5 条关键判断**；
3. **最重要的新证据**；
4. **最重要的反例/矛盾**；
5. **哪些旧方向被削弱或关闭**；
6. **当前 research question 是否更清楚，如何变化**；
7. **仍然阻塞方向选择的 Top 3 uncertainty**；
8. **下周唯一优先级最高的 literature cycle**；
9. **哪些问题已经不该继续查文献，而应该交给 baseline/data/experiment 模块**。

不要用“读了多少篇论文”作为主要进展指标。主要指标是减少了多少 decision-relevant uncertainty。
