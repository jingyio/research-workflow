# Prompt — 从 ChatGPT 历史刷新 Idea State

先读稳定 project state，再读 normalized ChatGPT digest。任务不是总结聊天，而是计算相对 current research state 的 delta。

用中文输出：
1. 未改变的 stable core；
2. 新增 commitments；
3. 变弱/条件化的 commitments；
4. 明确 rejected framing（后来的否决优先）；
5. 新 open questions；
6. 会影响检索同义词的 terminology changes；
7. 现在必须补证据的 claims；
8. 应启动/停止/重排的 literature routes；
9. 对 `current.md`、`rejected.md`、`decision_log.md`、`open_questions.md` 的 proposed edits。

不要把重复当证据，不要从 speculative brainstorming 推断稳定偏好，不要混淆论文事实和聊天观点；若修改会把私有/未发表细节写进 public repo，先显式标记。
