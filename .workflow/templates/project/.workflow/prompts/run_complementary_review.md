# Prompt — 运行互补型 Targeted Literature Review

给定一个 decision-relevant research question：

1. 明确它会改变哪个研究决策；
2. 从 `research/literature/routes.md` 选择 2–5 条互补 route；
3. 每条 route 写明它专门防止什么误判；
4. 生成包含同义词/领域标准术语的英文 query，不假设项目内部词汇是标准词；
5. 同时寻找支持与反驳证据；
6. 将候选注册进 paper pool；
7. 只深入能覆盖不同 method/evidence class 的最小论文集合；
8. 更新 claim ledger、contradiction log、research map、gap map、reading queue；
9. 最后用中文给出 Idea Delta，或者明确说明当前 idea 不应改变。

除非 decision question 本身就很宽，否则不要输出通用综述。
