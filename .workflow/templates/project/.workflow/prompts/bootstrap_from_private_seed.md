# Prompt — 从 Private Seed 启动研究会话

按顺序读取：`AGENTS.md`、`.workflow/SKILL.md`、public Idea State，以及 `research/private/idea_seed/` 下所有文件。

Private seed 是**研究记忆，不是科学证据**。

用中文输出：当前 north-star question、3–5 条最强研究承诺、不得随意复活的 rejected framing、按 decision impact 排序的 unresolved questions、当前应激活的 2–4 条 literature route、stop conditions，以及 private seed 与 public Idea State 的任何冲突。

除非文献已经把问题收敛到足够具体，否则不要提出模型架构。
