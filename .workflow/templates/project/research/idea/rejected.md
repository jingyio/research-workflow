# Rejected / Guarded Framings

This file is negative memory. Reopen an item only when new evidence directly addresses the reason it was rejected.

## R-001 — World-model framing as the core justification

**Status:** rejected as the primary framing.

**Reason:** treating compound or molecular edits as a time-like sequence can impose an artificial temporal interpretation. The usefulness of a state representation should come from the scientific structure of the prediction problem, not from forcing it into a sequential world-model analogy.

**May still be reused as:** a limited computational analogy, if it adds a concrete mechanism without distorting the scientific problem.

**Evidence needed to reopen:** a task in which sequential interventions and transition structure are intrinsic to the experimental process rather than imposed for modeling convenience.

## R-002 — “More structural input” as sufficient novelty

**Status:** guarded against.

**Reason:** simply adding coordinates, graphs, or structure tokens is not enough. The question is what object the model computes over, how that object changes, and why that should matter for the target/generalization regime.
