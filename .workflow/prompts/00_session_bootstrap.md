# Prompt — 启动/恢复研究会话

先读取 `AGENTS.md` 和 `.workflow/SKILL.md`，再按项目约定读取当前 Idea State、negative memory、open questions、latest synthesis 与 handoff；若本地存在 `research/private/bootstrap_packet.md`，也读取它。

本阶段**不要开始大范围检索**。请用中文输出：

1. 当前 north-star research question；
2. 3–5 条最强研究承诺及置信度；
3. 已否决/削弱、不得随意复活的 framing；
4. 当前最重要的开放问题，按“可能改变方向的程度”排序；
5. public Idea State 与 private seed 是否存在冲突；
6. 建议本会话做什么、不做什么。

若上下文足够，最后仅推荐一个最值得进入 `01_plan_cycle.md` 的问题。不要在此阶段设计模型架构。
