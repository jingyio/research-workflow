# Prompt — 用 ChatGPT 历史校正当前 Research Seed

输入包括 current public Idea State、current private seed、normalized ChatGPT research digest 和已有 decision log。

历史聊天是**provenance，不是 authority**。对每个有意义的历史 idea 标记：`confirm / refine / contradict / obsolete / new / uncertain`。

用中文输出：

1. **Stable core**：历史记录确认了哪些当前方向；
2. **Idea genealogy**：紧凑的研究问题演化链；仅在 digest 支持时使用日期；
3. **Reversals**：曾经探索但后来被否决/削弱的 idea，以及后来的理由；
4. **Recurring unresolved questions**：反复出现却仍未解决的问题；重复意味着 unresolved，不意味着 truth；
5. **Missing memory**：历史中存在但 seed 缺失的重要论文、概念、约束、决策；
6. **Search consequences**：哪些 literature route/query 应因此改变；
7. **Proposed edits**：分为 safe public edits、private-seed-only edits、需要人确认的 edits。

绝不能用旧的热情 brainstorming 覆盖更新、更明确的研究决策。
