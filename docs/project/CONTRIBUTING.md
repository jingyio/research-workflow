# Contributing

Contributions are welcome when they improve the **research workflow**, not when they add domain-specific claims without evidence.

Good contributions include:

- better literature-routing logic;
- safer ChatGPT-export handling;
- evidence/contradiction traceability;
- source-quality or novelty-audit checks;
- portable support for different coding/research agents;
- tests for the helper scripts.

Please keep the current scope boundary: the literature module is active, while reproduction, datasets, experiments, and writing remain placeholders unless a versioned roadmap change explicitly activates them.

Do not commit private conversation exports, credentials, copyrighted paper archives, or unpublished third-party material.
